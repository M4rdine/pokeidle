# Sprites oficiais de item — acervo da PokeAPI

Fonte: https://github.com/PokeAPI/sprites (`sprites/items/`)

O `LICENCE.txt` do repositório diz, literalmente:

> All image contents within are Copyright The Pokémon Company.
> This repository is distributed under CC0 1.0 Universal

Ou seja: o repositório é CC0, e a arte é copyright da The Pokémon Company. Os dois enunciados
convivem porque o segundo é um fato sobre a obra e o primeiro é a renúncia de direitos de quem
montou a coleção — não é a PokéCompany quem licencia em CC0.

**A decisão de usar assim mesmo é do dono do projeto**, e é a mesma já tomada para os sprites de
Pokémon que o jogo usa: é um fan game de Pokémon, sem monetização, na mesma posição de centenas
de Pokédex abertas. Está registrado aqui para que quem clonar o repositório saiba exatamente o
que está usando, em vez de descobrir depois.

## O que está aqui

Só os seis itens que a interface realmente desenha na tela. O acervo tem 905; trazer os 905
encheria o repositório de arte que ninguém usa.

| arquivo | onde aparece |
|---|---|
| `town-map.png` | botão Mapa |
| `poke-ball.png` | botão Time |
| `berry-pouch.png` | botão Mochila |
| `medal-box.png` | botão Pokédex |
| `coin-case.png` | botão Loja |
| `machine-part.png` | botão Configurações — é o mais próximo que existe; não há engrenagem no acervo, porque engrenagem é convenção de interface e não item de Pokémon |
